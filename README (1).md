# Pixel Path

A retro-inspired browser platformer built with HTML Canvas, CSS, and vanilla JavaScript. Run and jump through 20 increasingly challenging levels, collect coins, bounce on springs, ride moving platforms, and reach each finish flag.

## Play

**Live demo:** https://deepakpradhan1021.github.io/Pixel_Path/

> If the demo link is not live yet, enable GitHub Pages in the repository settings. The published URL is shown under **Settings → Pages**.

## Controls

- **Move:** A / D or Left / Right arrow keys
- **Jump:** W, Up arrow, or Space
- **Mobile:** On-screen touch controls
- **Restart:** R

## Features

- 20 stages with progressive difficulty and themed environments
- Pixel-inspired graphics drawn directly on the canvas
- Coin collection and coin blocks
- Enemies and jump-stomp interactions
- Springs, moving platforms, and checkpoints
- Keyboard and touch input
- Level progress saved in the browser

## Run locally

Download or clone this repository, then open `index.html` in a modern web browser. No build step or external assets are required.
